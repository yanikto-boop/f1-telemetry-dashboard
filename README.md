# F1 25 Telemetry Dashboard 🏁

Автономное Flutter-приложение (Android/Windows), которое **напрямую** принимает UDP-телеметрию
из F1 25 (формат 2025), рисует полный дашборд и записывает все круги локально.
Питон-бэкенд не нужен.

## Возможности
- **Дашборд:** скорость, передача, rev-LED, газ/тормоз/руль, DRS, карта трассы,
  шины (темп/износ/давление), ERS + топливо, тайминг с секторами, лидерборд, события.
- **Круги:** все заезды по каждой трассе (отдельный файл на трассу), лучший круг, секторы.
- **AI-анализ** кругов через OpenRouter (гоночный инженер даёт советы).
- **Автообновление** из GitHub Releases.

## Режимы приёма
- **LAN** — игра шлёт UDP на IP телефона (приложение показывает локальные IP).
- **Этот ПК** — приложение на том же ПК, игра шлёт на `127.0.0.1`.

Bind идёт на `0.0.0.0:20777`, так что физически ловятся оба случая.

## Настройка игры (один раз)
F1 25 → `Settings → Telemetry Settings`:
- UDP Telemetry: **On**, Broadcast: **Off**
- UDP IP Address: IP устройства с приложением (или `127.0.0.1`)
- UDP Port: **20777**, Format: **2025**, Your Telemetry: **Public**

## Сборка
```bash
cp lib/secrets.example.dart lib/secrets.dart   # впиши ключ OpenRouter (опционально)
flutter pub get
flutter build apk --release
```

`lib/secrets.dart` в `.gitignore` и в репозиторий не попадает.

## Установка
Скачай свежий `app-release.apk` из [Releases](../../releases), поставь на телефон,
в настройках выбери режим и порт.
